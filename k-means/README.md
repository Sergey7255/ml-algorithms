# Алгоритм кластеризации K-Means

Данный репозиторий содержит реализацию алгоритма кластеризации K-Means (К-средних) с использованием множественной инициализации центров для поиска оптимального разбиения.

## Требования и установка
- Python 3.8+  

Установка необходимых зависимостей:
```bash
pip install scikit-learn numpy matplotlib
```

## Запуск и вывод программы
Команда для запуска скрипта: 
```bash
python k-means.py
```
В результате программа выведет точечный график с разделением объектов на 3 кластера и отметками их центров, а также напечатает в консоль массивы с итоговыми метками кластеров и координатами лучших центров.

## Детали реализации
- Алгоритм поочередно выполняет два действия. На *E-шаге* каждый объект относится к ближайшему центру, а на *M-шаге* центры пересчитываются как среднее значение координат всех точек, попавших в кластер.
- Применяется **Евклидово расстояние** для вычисления дистанции от каждого объекта до текущих центров кластеров.
- **Множественная инициализация**: Поскольку алгоритм чувствителен к начальному случайному расположению центров, скрипт выполняет 10 независимых запусков (`m = 10`). Итоговым признается вариант с минимальной суммой квадратов внутрикластерных расстояний.
- **Защита от пустых кластеров**: Если в процессе работы алгоритма какой-либо кластер теряет все свои точки, скрипт автоматически назначает ему новый центр, выбрав случайную точку из исходного набора данных. Это предотвращает ошибки вычислений и «вырождение» кластеров.
