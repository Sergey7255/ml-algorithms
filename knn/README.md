# Метод ближайших соседей (KNN)

Данный репозиторий содержит реализацию алгоритма метода ближайших соседей с использованием окна Парзена-Розенблатта с ядром Епанечникова и кросс-валидацией Leave-One-Out (LOO) для задачи классификации набора данных Iris.

## Требования и установка
- Python 3.8+  

Установка необходимых зависимостей:
```bash
pip install scikit-learn numpy matplotlib
```

## Запуск и вывод программы 
Команда для запуска скрипта:
```bash 
python knn.py
```  
В результате программа выведет график зависимости ошибки LOO от количества соседей (k от 1 до 20), а также напечатает в консоль оптимальное значение k, ошибку LOO и точность (accuracy).
### Пример вывода
Оптимальное k: 14  
LOO(k): 0.02666666666666667  
Accuracy: 0.9736842105263158

## Детали реализации
- Основой скрипта является **Метод Парзеновского окна**. В обычном knn мы берем ближайших соседей и все их голоса равны, с окном Парзена мы подсчитываем "вес" каждого соседа, вес зависит от расстояния до соседа.
- С помощью функции **ядра Епанечникова** мы непосредственно подсчитываем вес каждого соседа. Она ограничивает влияние слишком далеких объектов (за пределами окна) и имеет вид:  
K(u) = (3/4) * (1 - u^2) * I(|u| ≤ 1)
- **Метод кросс-валидации** проверяет качество выполнения программы и находит оптимальное количество соседей. Алгоритм поочередно исключает каждый объект из обучающей выборки, обучает модель на оставшихся и проверяет предсказание на исключенном.
